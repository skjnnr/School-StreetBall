# Half Court 1v1

A lightweight browser-based 3D half-court basketball prototype.

## Controls
- WASD: Move
- Shift: Sprint
- E: Crossover
- Q: Behind-the-back
- Tab: Between-the-legs
- R: Hesitation
- F: Hold and release to shoot

The CPU guards movement but does not contest, block, or modify shooting odds.

## Run
Because this uses JavaScript modules, serve the folder with a web server or upload it to GitHub Pages.
GitHub Pages works directly once these files are in the repository root.

Note: Three.js is loaded from jsDelivr, so the game needs an internet connection.
